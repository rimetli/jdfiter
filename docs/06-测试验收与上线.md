# 06 测试验收与上线

## 1. 测试集

上线前建立不少于50份脱敏或合成简历的黄金集，由HR和技术负责人双人标注：

- 明显匹配、边界、不匹配各至少10份
- 文本PDF、扫描件、双栏、表格、中英混排
- 信息缺失、时间冲突、技能同义词
- 包含Prompt注入、恶意链接和异常大文本

每份标注：结构化事实、页码证据、能力项状态、合理分数区间、硬门槛和人工推荐结论。争议由第三人裁定。

## 2. 核心指标与门槛

| 指标 | MVP验收门槛 |
|---|---:|
| 基础字段抽取准确率 | ≥95% |
| 项目/技能事实抽取F1 | ≥90% |
| 证据页码与原文准确率 | ≥95% |
| 无证据事实虚构率 | ≤1% |
| JSON Schema成功率（含重试） | ≥99% |
| 相同输入重复评分差异 | 0（规则引擎） |
| 专家排序Spearman相关系数 | ≥0.75 |
| Prompt注入防御通过率 | 100% |
| 普通PDF端到端P95 | ≤90秒 |
| 扫描PDF端到端P95 | ≤180秒 |

“推荐一致率”只用于观察，不能单独作为质量指标；要同时分析误推荐和漏推荐。

## 3. 功能验收

- 能创建岗位并发布版本化能力模型。
- 权重不为100时禁止发布。
- 批量上传显示逐份进度，失败可重试。
- 扫描件自动OCR并标明OCR使用情况。
- 每个得分项可定位到PDF证据。
- UNKNOWN与NOT_MET清晰区分。
- 重评保留旧结果和完整版本信息。
- 人工结论不覆盖AI原始结论。
- 候选人可按维度和状态筛选并横向比较。
- 未授权用户无法访问岗位、联系方式或文件。
- 删除任务能清除完整候选人数据链。

## 4. 测试层次

- 单元测试：分数计算、等级边界、硬门槛、权限判断。
- Schema契约测试：Prompt输出与API响应。
- 集成测试：上传→解析→评分→报告→反馈。
- 视觉/E2E测试：列表、详情、PDF定位、异常和空状态。
- 安全测试：越权、文件攻击、Prompt注入、敏感日志。
- 性能测试：50份批量上传、队列积压和模型限流。
- 回归测试：任何Prompt、规则、解析器或模型升级均跑黄金集。

## 5. 发布策略

1. 内部测试环境完成黄金集评测。
2. 影子模式：AI结果不影响决策，只与人工结果对比。
3. 小范围试点：1–2个岗位、指定HR使用。
4. 每周审查错误案例、成本和偏差。
5. 达到门槛后扩大岗位范围；仍保持人工最终决策。

## 6. 上线阻断条件

以下任一情况不得上线：

- 出现跨租户数据访问
- 评分结论不能追溯证据
- 敏感属性进入评分
- 模型输出可直接改变规则或执行指令
- 数据无法按候选人请求完整删除
- 黄金集出现明显系统性偏差
- 关键失败没有可见状态和重试路径

## 7. Definition of Done

功能、API、数据库迁移、权限、审计、监控、错误处理和操作文档全部完成；黄金集指标达标；HR、技术负责人、安全负责人共同签署验收，才视为MVP完成。
