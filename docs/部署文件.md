# AI 招聘简历筛选系统部署指南

> 标准部署方式：**腾讯云 Ubuntu 24.04.4 LTS + OrcaTerm 上传 ZIP + Docker Compose**。
>
> 本文面向服务器新手。严格按顺序执行即可；不需要安装 Python、Node.js，不需要 Git 克隆、虚拟环境、`resumeapp` 账号或 systemd 服务。

## 1. 部署结果

部署完成后，服务器运行三个 Docker 容器：

```text
浏览器 → Nginx（HTTPS）→ Web 容器（Vue 前端 + /api 反向代理）
                           ├─ API 容器（FastAPI）
                           └─ Worker 容器（简历解析、JD 分析、评分）
                                      │
                         腾讯云 MySQL / 外部模型 API
```

- Web 容器仅监听 `127.0.0.1:8080`，不会直接暴露到公网。
- 宿主机 Nginx 是唯一公网入口，负责域名与 HTTPS。
- 简历文件保存在服务器 `/srv/data/ai-resume-screening/storage`。
- 4 核 4GB / 48GB 磁盘适合低并发、小团队使用；不要在此服务器本地部署 MySQL 或大模型。

## 2. 部署前准备

准备以下内容，**不要**发送到聊天或提交到 Git：

1. 腾讯云 Ubuntu **24.04.4 LTS** 云服务器及公网 IP（登录账号为 `ubuntu`）。
2. （可选）已解析到该公网 IP 的域名，例如 `recruit.example.com`。没有域名也可先用公网 IP 完成部署和验证，后续再绑定域名与 HTTPS。
3. 腾讯云 MySQL 8 的地址、数据库名、账号和密码。
4. 模型服务的 API 地址、API Key 和模型名。
5. 本仓库 GitHub 页面下载的 ZIP 文件，通常名为 `jdfiter-main.zip`。
6. 本地项目的 `backend/.env` 文件，复制后重命名为 `ai-resume-screening.env`。

腾讯云安全组只开放以下入站端口：

| 端口 | 用途 | 建议 |
|---|---|---|
| 22 | SSH / OrcaTerm | 限制为管理员固定 IP |
| 80 | HTTP、证书验证 | 公网开放 |
| 443 | HTTPS | 公网开放 |

不要开放 `3306`、`8000`、`8080`。在腾讯云 MySQL 白名单中加入这台 CVM 的出口公网 IP（或同 VPC 私网网段）。

## 3. 使用 OrcaTerm 上传文件

> 操作规则：只复制文档中灰色代码块里的命令；**不要**复制终端提示符（例如 `ubuntu@VM:~$`），也不要把 `ls` 命令执行后的列表结果再次粘贴到终端。提示符和列表文字不是命令。

先确认当前系统与登录账号。预期输出包含 `Ubuntu 24.04.4 LTS` 和 `ubuntu`：

```bash
cat /etc/os-release | head -n 2
whoami
```

然后创建专用上传目录。下面命令会自动使用当前登录账号，不再写死 `ubuntu`：

```bash
sudo install -d -o "$(id -un)" -g "$(id -gn)" -m 700 /tmp/ai-resume-upload
```

然后在 OrcaTerm 的文件管理器中，进入路径 `/tmp/ai-resume-upload/`。不要使用或删除 `/tmp/` 目录中已有的系统文件。

上传两个文件到该专用目录：

```text
jdfiter-main.zip
ai-resume-screening.env
```

然后在 OrcaTerm 终端执行：

```bash
cd /tmp/ai-resume-upload
ls -lh jdfiter-main.zip ai-resume-screening.env
```

只有两个文件都显示出来，才继续下一步。

> 若 ZIP 文件名称不是 `jdfiter-main.zip`，后续命令中的文件名替换为实际名称。`/tmp/ai-resume-upload/` 仅用于上传和解压，服务器重启后其中的文件可能被清理，这是正常的。

## 4. 解压源码并放置配置文件

以下命令整段复制到 OrcaTerm 终端执行：

```bash
sudo apt update
sudo apt install -y unzip nginx

sudo mkdir -p /tmp/ai-resume-release /opt/ai-resume-screening
sudo unzip -qo /tmp/ai-resume-upload/jdfiter-main.zip -d /tmp/ai-resume-release

SOURCE_DIR="$(find /tmp/ai-resume-release -mindepth 1 -maxdepth 1 -type d | head -n 1)"
test -n "$SOURCE_DIR" || { echo "未找到 ZIP 内的源码目录"; exit 1; }
sudo cp -a "$SOURCE_DIR"/. /opt/ai-resume-screening/

sudo install -o root -g root -m 600 \
  /tmp/ai-resume-upload/ai-resume-screening.env \
  /opt/ai-resume-screening/backend/.env

test -f /opt/ai-resume-screening/docker-compose.yml && echo "源码准备完成"
test -f /opt/ai-resume-screening/backend/.env && echo "配置文件准备完成"
```

预期看到：

```text
源码准备完成
配置文件准备完成
```

如果没有看到这两行，不要继续执行，先检查：

```bash
ls -la /opt/ai-resume-screening
ls -la /tmp/ai-resume-release
```

## 5. 检查服务器环境配置

编辑服务器上的配置文件：

```bash
sudo nano /opt/ai-resume-screening/backend/.env
```

必须检查并改为服务器实际值：

```dotenv
APP_ENV=production
APP_SECRET=至少32位随机字符串
CORS_ORIGINS=["https://recruit.example.com"]

MYSQL_HOST=腾讯云MySQL地址
MYSQL_PORT=3306
MYSQL_DATABASE=resume_screening
MYSQL_USERNAME=数据库账号
MYSQL_PASSWORD=数据库密码
MYSQL_SSL=true
MYSQL_SSL_CA=

LLM_PROVIDER=openai-compatible
LLM_BASE_URL=模型接口地址
LLM_API_KEY=模型密钥
LLM_MODEL=文本模型名称
RESUME_LLM_ENABLED=true

RESUME_VISION_ENABLED=true
RESUME_VISION_MODEL=支持图片识别的模型名称
```

说明：

- 没有域名时，`CORS_ORIGINS` 可临时写为 `["http://服务器公网IP"]`；申请 HTTPS 后改回实际域名。
- Docker 会自动使用容器内的简历路径，不需要修改 `LOCAL_STORAGE_PATH`。
- `MYSQL_SSL_CA` 不需要证书时留空；腾讯云 MySQL 强制 CA 时填写证书在服务器内的绝对路径。
- 保存 Nano：`Ctrl + O` → 回车 → `Ctrl + X`。

## 6. 安装 Docker 并启动系统

以下命令使用 **Ubuntu 24.04 官方软件源**安装 Docker 和 Compose，随后创建 2GB Swap（适合 4GB 内存）、简历存储目录、构建镜像、创建数据库表并启动全部容器。该方式不依赖 `download.docker.com`，适合腾讯云网络环境：

```bash
cd /opt/ai-resume-screening

sudo rm -f /etc/apt/sources.list.d/docker.sources
sudo rm -f /etc/apt/keyrings/docker.asc
sudo apt update
sudo apt install -y docker.io docker-compose-v2
sudo systemctl enable --now docker
sudo docker compose version

# 腾讯云镜像加速：避免 Docker Hub 下载超时。
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json > /dev/null <<'EOF'
{
  "registry-mirrors": ["https://mirror.ccs.tencentyun.com"]
}
EOF
sudo systemctl restart docker
sudo docker info | grep -A 2 'Registry Mirrors'

# Dockerfile 已内置腾讯云 PyPI 镜像、120 秒下载超时和 5 次重试，
# 用于避免构建时从 files.pythonhosted.org 下载 Python 依赖超时。

# 4GB 内存服务器建议只执行一次。
if ! swapon --show | grep -q '/swapfile'; then
  sudo dd if=/dev/zero of=/swapfile bs=1M count=2048 status=progress
  sudo chmod 600 /swapfile
  sudo mkswap /swapfile
  sudo swapon /swapfile
  echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
fi
free -h

sudo mkdir -p /srv/data/ai-resume-screening/storage
sudo chown -R 10001:10001 /srv/data/ai-resume-screening
sudo chmod 750 /srv/data/ai-resume-screening /srv/data/ai-resume-screening/storage

sudo docker compose build
sudo docker compose run --rm api python -m alembic upgrade head
sudo docker compose up -d
sudo docker compose ps

curl -fsS http://127.0.0.1:8080/api/v1/health
curl -fsS http://127.0.0.1:8080/api/v1/health/database
```

预期健康检查返回：

```json
{"status":"ok"}
{"status":"ok","database":"mysql"}
```

如果数据库健康检查失败，优先检查：腾讯云 MySQL 白名单、MySQL 地址/密码、`MYSQL_SSL` 与 API 容器日志：

```bash
cd /opt/ai-resume-screening
sudo docker compose logs --tail=100 api
```

## 7. （可选）配置域名、Nginx 和 HTTPS

没有域名时也需要完成本节的 Nginx 配置，才能通过 `http://服务器公网IP` 访问；只需将 `server_name` 改为 `_`，并跳过 Certbot 申请证书的命令。生产环境涉及登录与简历上传，建议后续尽快绑定域名并改用 HTTPS。

把 Docker 专用 Nginx 模板复制到系统配置目录：

```bash
sudo cp /opt/ai-resume-screening/deploy/nginx/ai-resume-screening-docker.conf \
  /etc/nginx/sites-available/ai-resume-screening

sudo nano /etc/nginx/sites-available/ai-resume-screening
```

将文件中的：

```nginx
server_name recruit.example.com;
```

改为你的真实域名，例如：

```nginx
server_name recruit.your-company.com;
```

没有域名时，改为：

```nginx
server_name _;
```

启用配置并申请证书：

```bash
sudo ln -s /etc/nginx/sites-available/ai-resume-screening /etc/nginx/sites-enabled/ai-resume-screening
test -L /etc/nginx/sites-enabled/default && sudo unlink /etc/nginx/sites-enabled/default || true

sudo nginx -t
sudo systemctl reload nginx
```

没有域名时，到此结束本节，直接访问：

```text
http://服务器公网IP
```

已有域名时，继续申请证书：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d recruit.your-company.com
```

证书成功后，修改 `/opt/ai-resume-screening/backend/.env` 的 `CORS_ORIGINS` 为实际 HTTPS 域名，然后重新加载容器：

```bash
cd /opt/ai-resume-screening
sudo docker compose up -d
```

## 8. 首次初始化

初始化组织（只在空数据库第一次部署时执行一次）。将 `<访问地址>` 替换为 `http://服务器公网IP` 或已配置的 `https://你的域名`：

```bash
curl -X POST <访问地址>/api/v1/setup/bootstrap \
  -H 'Content-Type: application/json' \
  -d '{"organization_name":"你的公司或团队"}'
```

然后在浏览器打开：

```text
<访问地址>/login
```

创建管理员账号。管理员登录后可创建普通账户、岗位和简历。

## 9. 常用运维命令

所有命令先进入项目目录：

```bash
cd /opt/ai-resume-screening
```

| 目的 | 命令 |
|---|---|
| 查看服务状态 | `sudo docker compose ps` |
| 查看 API 日志 | `sudo docker compose logs -f api` |
| 查看简历解析/评分日志 | `sudo docker compose logs -f worker` |
| 重启全部服务 | `sudo docker compose restart` |
| 停止服务 | `sudo docker compose down` |
| 启动服务 | `sudo docker compose up -d` |
| 检查磁盘 | `df -h /srv/data/ai-resume-screening/storage` |

### 从 GitHub 更新版本（ZIP 部署方式）

本部署方式由 ZIP 解压安装，`/opt/ai-resume-screening` 没有 `.git` 目录，**不能执行 `git pull`**。每次 GitHub 有新版本时，按以下步骤更新。更新前建议先备份数据库。

1. 在本机打开 [GitHub main 分支 ZIP 下载地址](https://github.com/rimetli/jdfiter/archive/refs/heads/main.zip)，下载最新文件。
2. 使用 OrcaTerm 上传并覆盖服务器上的文件：

```text
/tmp/ai-resume-upload/jdfiter-main.zip
```

3. 在服务器终端执行以下命令。它会使用新的临时解压目录，避免误把旧 ZIP 再次复制到项目中；**不会覆盖**已有的 `backend/.env` 和 `/srv/data/ai-resume-screening/storage` 中的简历文件：

```bash
cd /opt/ai-resume-screening

RELEASE_DIR="$(mktemp -d /tmp/ai-resume-release.XXXXXX)"
unzip -qo /tmp/ai-resume-upload/jdfiter-main.zip -d "$RELEASE_DIR"

SOURCE_DIR="$(find "$RELEASE_DIR" -mindepth 1 -maxdepth 1 -type d | head -n 1)"
test -n "$SOURCE_DIR" || { echo "未找到 ZIP 内的源码目录"; exit 1; }

sudo cp -a "$SOURCE_DIR"/. /opt/ai-resume-screening/
```

4. 构建、执行数据库迁移并重启容器：

```bash
cd /opt/ai-resume-screening

sudo docker compose build
sudo docker compose run --rm api python -m alembic upgrade head
sudo docker compose up -d --force-recreate

sudo docker compose ps
curl -fsS http://127.0.0.1:8080/api/v1/health
```

预期最后一条返回：

```json
{"status":"ok"}
```

5. 若本次更新说明包含后台 JD 分析功能，可额外确认 Worker 已是最新版：

```bash
grep -n "ANALYZE_JOB_JD" /opt/ai-resume-screening/backend/app/worker.py
```

> 不要在版本更新时再次复制 `ai-resume-screening.env`，否则可能意外覆盖服务器已经配置好的数据库、模型和域名参数。若 Docker 构建失败，先运行 `sudo docker compose logs --tail=100 api worker` 查看错误。

## 10. 备份与安全

- 每日启用腾讯云 MySQL 自动备份，并定期验证恢复。
- 定期备份 `/srv/data/ai-resume-screening/storage` 到腾讯云 COS；其中包含原始简历文件。
- 不要将 `.env`、PDF 简历、数据库导出文件上传到 GitHub。
- 只开放 `22`、`80`、`443`；不要开放 MySQL、API 或 Docker 容器端口。
- 定期执行 `sudo apt update && sudo apt upgrade -y`，并在维护窗口更新项目。
- Docker 对外发布端口可能绕过 UFW，因此本项目固定使用 `127.0.0.1:8080`，不要修改为公网监听。
