# AI 招聘简历筛选系统

面向 HR 和技术负责人的 AI 辅助筛选系统。系统负责提取简历事实、依据已确认的岗位规则评分、展示证据并生成面试建议；最终招聘决定始终由人工完成。

## MVP 核心原则

1. 先确认岗位能力模型，再评估候选人。
2. 所有判断必须引用简历证据；证据不足标记为“未知”，不能推断为“不具备”。
3. 规则计算分数，LLM负责事实抽取和解释。
4. 每次评估固定岗位、规则、Prompt和模型版本，结果可复现、可审计。
5. 默认进行盲筛，姓名、性别、年龄、照片等信息不参与评分。

## MVP 用户流程

```text
创建岗位 → AI解析JD → 人工确认能力模型 → 上传简历
→ 解析/OCR → 事实提取 → 规则评分 → 报告与证据
→ 人工决定 → 面试反馈
```

## 建议实现顺序

1. 数据库、文件上传和异步任务。
2. 岗位创建、JD分析确认。
3. 简历解析、结构化抽取和证据定位。
4. 确定性评分引擎。
5. 候选人列表、详情和横向对比。
6. 权限、审计、人工反馈和验收测试。
